# BIGSHOOTER

Alberta hunting GPS beta web app. Open index.html through HTTPS hosting (GitHub Pages or Netlify) to use browser geolocation.

Features: GPS position, saved truck and markers, GPX route tracking/export, satellite basemap, optional Alberta WMU GIS layer, species habitat notes, and links to official regulations.

**Limitations:** Map tiles and WMU layer require internet. No validated Crown land layer, season lookup, wildlife prediction, or dependable offline backcountry navigation yet. Never rely on this beta as a sole safety or legal reference.

For GitHub Pages, enable Settings → Pages → Deploy from a branch → main / root (availability depends on repository visibility and plan).
